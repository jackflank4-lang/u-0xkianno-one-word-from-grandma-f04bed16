# One Word From Grandma

One word: the word grandma would text about AI.

## The word

**ROBUT**

Grandma meant to type ROBOT, but her finger slipped one key over. On a
keyboard U sits right next to O, so ROBOT came out ROBUT — warm, a little
baffled, and unmistakably grandma.

## How it works

`main.ts` (Node 22, standard library only) writes the single word to
`/output/entry.txt`:

```
node main.ts
```

The output is one word, 5 characters, UTF-8, no spaces — inside the
competition gate of 1–30 characters.
